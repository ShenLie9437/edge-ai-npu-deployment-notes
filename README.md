# Edge AI / NPU Deployment Notes

這是一份關於邊緣裝置 AI 模型部署（NPU / 嵌入式推論加速器）的通用方法論筆記集，
記錄我在實務工作中反覆遇到、並歸納出可複用排查邏輯的技術問題。

內容聚焦在「原理」與「系統化排查方法」，而非特定框架或平台的操作手冊，
用來示範問題的判斷邏輯與驗證思路。

目前涵蓋的主題：量化精度陷阱、硬體算子相容性盤點、記憶體與緩衝區限制排查、
系統瓶頸定位方法論，以及免訓練的快速驗證技巧。

每篇筆記格式統一：問題現象 → 原理說明 → 系統化排查步驟 → 一般性解法 / checklist，
方便同領域工程師快速比對是否遇到類似情況。
